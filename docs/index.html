Toute l’actualité

À savoir : la sélection automatique ne lit pas le texte intégral des articles ; elle repère des signaux dans les titres, la date, les rubriques et les noms de médias. Les suggestions et scores doivent être vérifiés avant utilisation. Les requêtes explorent Google Actualités et des flux de podcasts chaque jour via GitHub Actions. La couverture peut être partielle et les dates sont celles des publications. Les signaux sensibles sont des alertes à contrôler humainement, pas un diagnostic de crise. Le bouton actualiser recharge les données disponibles, sans lancer une nouvelle collecte.
